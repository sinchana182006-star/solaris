# 🌌 Solaris – 3D Solar System Explorer

Solaris is an interactive 3D Solar System Explorer built using React, Three.js, and Node.js.
## 🚀 Features

- 🌍 Interactive 3D Solar System
- 🪐 Explore planets and their details
- 🔐 User Registration and Login
- 🔭 Cosmic Lens
- 🚀 Space Missions
- 📚 Cosmic Notes
- 📝 Solar System Quiz
- 📄 Solar System PDF
- 👤 User Profile

## 🛠️ Technologies

### Frontend
- React
- Three.js
- React Three Fiber
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
